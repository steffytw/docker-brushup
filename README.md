# Docker
Docker is a platform for developing, shipping, and running applications inside lightweight containers.
Containers package an application with all its dependencies, ensuring it runs consistently across different environments.

## Key Concepts:
- Images: Blueprints for containers; created using a Dockerfile.
- Containers: Running instances of Docker images.
- Dockerfile: A text file with instructions to build a Docker image.
- Docker Hub: A registry for Docker images.
- Volumes: Mechanism to persist data outside containers.
- Networking: Connects containers to each other or the internet.
